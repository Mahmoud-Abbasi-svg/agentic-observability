# References

The papers this design was read against. The PDFs are not redistributed here — publisher
copies are licensed for personal use, and several of these are open access anyway, so a
resolvable identifier is more useful than a file.

Titles and identifiers below were read off the papers themselves, not recalled.

## Agent observability

- Zheng, Hu, Yu, Quinn. **AgentSight: System-Level Observability for AI Agents Using eBPF.**
  PACMI '25, Seoul. <https://doi.org/10.1145/3766882.3767169> (CC BY 4.0)
  — Observes agents from *outside* the application, at stable system interfaces. The closest
  thing in this corpus to the position this project takes on instrument placement.

- Fournier, Limonad, David (IBM Research). **Agentic AI Process Observability: Discovering
  Behavioral Variability.** PMAI25 workshop, CEUR-WS. arXiv:2505.20127 (CC BY 4.0)

- **Unified Agentic Interfaces is All You Need for AI Agent Observability.**

## Observability data modelling

- Pei, Li, Wang, Cui, Nie, Zhou, Situ, Zhang, Zhang, Wen, Xie, Li, Pei. **UModel: An
  Agent-Ready Observability Data Modeling Method at Scale.** arXiv:2606.04799
  — Deployed at Alibaba Cloud. The ontology is built by humans so that agents can query it;
  this project's counter-position is that the instrumentation boundary itself should move.

- Videsjorden, Song, Goknil, Roman, Soylu (SINTEF). **LUMEN: Enhancing IoT System
  Observability with Multi-Agent Large Language Models and Knowledge Graphs.**
  ACM Trans. Internet Things 7(2), Art. 18, April 2026.
  <https://doi.org/10.1145/3772077> (CC BY 4.0)

- Matharaarachchi, Moraliyage, Mills, Gamage, De Silva, Manic. **Addressing hallucinations in
  generative AI agents using observability and dual memory knowledge graphs.**
  Knowledge-Based Systems 338 (2026) 115469.
  <https://doi.org/10.1016/j.knosys.2026.115469> (CC BY 4.0)

## Agentic network operations

- **MX-AI: Agentic Observability and Control Platform for Open and AI-RAN.**
  — Reports a 4.1/5 coherence ceiling and states 5/5 is "unlikely without better evidence
  plumbing". That sentence is the motivation for this project's self-assessment layer.

- **A Hierarchical Multi-Agent Reinforcement Learning Approach for Adaptive Observability.**

- **An Agentic AI Framework for Observability-Driven Self-Healing and Auto-Remediation in
  Cloud Infrastructure.**

- **Advanced AI-Driven Automation for Smarter Networks: The Modern Observability Advantage.**
